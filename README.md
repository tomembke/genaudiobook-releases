Download: [GenAudioBook_Pro.dmg (latest)](https://github.com/tomembke/genaudiobook-releases/releases/latest/download/GenAudioBook_Pro.dmg) · [All releases](https://github.com/tomembke/genaudiobook-releases/releases) · Website: [genaudiobook.com](https://www.genaudiobook.com) · Installation help: [genaudiobook.com/install](https://www.genaudiobook.com/install/)

Requires a Mac with Apple Silicon (M1 or newer).

## Engines (v1.0.4)

All engines are installed from inside the app via **Model Manager** (button next to "KI Engine" / "AI Engine").

| Engine | Languages | Download | Voice cloning | Model license |
|---|---|---|---|---|
| Chatterbox (built in) | Standard/Turbo: EN · Multilingual: 23 languages incl. DE | ~1–3 GB | Yes | MIT |
| Kokoro v1.0 | EN, ES, FR, IT, PT, HI, JA, ZH | ~1.5 GB | No | Apache 2.0 |
| F5-TTS | EN, ZH | ~3 GB | Yes | CC-BY-NC 4.0 (non-commercial) |
| MeloTTS | EN, ES, FR, ZH, JA, KO | ~3 GB | No | MIT |
| CosyVoice 2 | ZH, EN, JA, KO | ~6 GB | Yes | Apache 2.0 |

Engines are stored in `~/Library/Application Support/GenAudioBook/engines/` and can be removed again in the Model Manager.
